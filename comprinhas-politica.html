Política Privacidade

Esta política de privacidade informa você sobre as nossas praticas com suas informações e dados dentro do nosso app. No presente momento esse app é criado por Chrystian Salgado Martins dos Santos, com email para contato ‘salgado.dev@gmail.com’. Caso você usuário não esteja de acordo com esta Política, você não deve usar nosso aplicativo, em caso de questionamento ou revisão da nossa politica envie- nos um email sobre a situação desejada.

Coleta de dados

Nosso app não faz nenhuma coleta de dados sensíveis, e nem que identificam ou faça distinção entre os usuários, os únicos dados usados são para fim de melhoria do app no geral que são fornecidos pelo próprio sistema operacional.

Como usamos os dados coletados

Os dados coletados são usados para entender pontos de melhorias de layout, falhas do aplicativo e oferecer suporte ao usuário caso necessário.

Com quem compartilhamos seus dados

Os dados que coletamos por meio do seu próprio sistema para melhoria do aplicativo e entregar uma usabilidade melhor para você, são exclusivamente compartilhado com nossos provedores de análise (Google LLC), que são responsáveis por ajudar a entender melhor nossa base de usuários você pode consultar a politica do google em Google Privacy.

Onde armazenamos suas informações

As informações concedidas para nosso sistema são armazenadas no servidor do Google LLC, e são se uso exclusivo seu e com quem você queira compartilhar. E você pode escolher apagar a qualquer momento as listas salvas no nosso aplicativo. Os dados que você escolher excluir serão irrecuperáveis, ou seja excluídos permanentemente.
